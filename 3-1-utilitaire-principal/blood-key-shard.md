# Fragment de clé sanguine

## Description

Le fragment de clé sanguine est l'objet nécessaire pour obtenir une clé sanguine. Avec 9 fragments, le joueur peut en construire une.

Les fragments de clé sanguine sont obtenables en étant sur le podium de l'événement Bain de Sang. Voici un tableau décrivant le nombre de fragment en fonction de la place sur le podium:

| Place | Nombre de fragments |
| :---: | :---: |
| 1 | 3 |
| 2 | 2 |
| 3 | 1 |
