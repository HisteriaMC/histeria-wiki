# Clé sanguine

## Description

La clé sanguine est une clé disponible en la construisant à partir de 9 [fragments de clé sanguine](https://histeria.fr/wiki/7-boss/boss-key-shard). Vous pouvez l'utiliser sur la box **blanche/beige et rouge** aux spawns de chaque serveur.
