# Meteor

## Informations
L'enchantement Rust est fusionnable avec une [hache](https://histeria.fr/wiki/2-equipement/histerite-axe).
Quand le porteur frappe un ennemi, il a une chance de retirer 0.5 coeur de vie supplémentaire à son adversaire et de réduire la durabilité de son armure.

**Niveau maximum :** 5

| Niveau | Pourcentage d'activation |
| --- | --- |
| 1 | 1 % |
| 2 | 1.25 % |
| 3 | 1.5 % |
| 4 | 1.75 % |
| 5 | 2 % |
