# Timber

## Obtention
Cet enchantement n'est disponible **que dans les coffres légendaires d'arène**

## Informations
L'enchantement d'arène Timber est fusionnable avec une hache. Quand le porteur casse un bloc de bois, il a une chance de gagner de l'argent en fonction du niveau de l'enchantement (20 $ * niveau).


**Niveau maximum :** 3

| Niveau | Chances de trouver un fossile |
| --- | --- |
| 1 |	0.0972% |
| 2 |	0.1134% |
| 3 |	0.1296% |
