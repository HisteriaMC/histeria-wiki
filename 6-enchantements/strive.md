# Strive

## Informations
L'enchantement Strive est fusionnable avec une [pièce d'armure](https://histeria.fr/wiki/2-equipement).
Quand le porteur est frappé, il a une chance de réparer faiblement son armure (environ de 10 de durabilité) !

**Niveau maximum :** 5

| Niveau | Pourcentage d'activation |
| --- | --- |
| 1 | 0.5 % |
| 2 | 0.625 % |
| 3 | 0.75 % |
| 4 | 0.875 % |
| 5 | 1 % |
