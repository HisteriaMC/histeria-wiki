# Primes

## Description

Le système de primes permet de placer de l'argent sur la mort d'un joueur, et quand ce joueur meurt, l'assassin récupère toutes les mises.

Pour accéder au menu des primes, il faut utiliser la commande **`/bounty`**. Dans le menu, on peut trouver les primes les plus élevées. Pour placer une prime, il faut utiliser la commande **`/bounty place <joueur> <mise>`**, le surenchérissement d'une prime déjà existante peut également se faire via le menu.
